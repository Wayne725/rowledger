# RowLedger 使用指南

日期：2026-10-05

RowLedger 在電腦上比對訂單與收款資料，產生可追查來源的報告。不需帳號、API 金鑰或上傳資料。

## 安裝與展示

需要 Python 3.11 以上。在專案資料夾執行：

```sh
python -m venv .venv
# macOS / Linux
source .venv/bin/activate
# Windows PowerShell 改用：.venv\Scripts\Activate.ps1
python -m pip install .
rowledger demo --out runs/demo
```

開啟 `runs/demo/report.html`。26 筆合成資料會得到 5 組自動匹配、16 筆待確認。點選編號可看原始欄位、來源位置與判定原因；可搜尋及篩選異常。

## 處理自己的檔案

將真實資料放在被 Git 忽略的 `data/`。兩份表預設欄位為 `order_id`、`amount`、`currency`：

```sh
rowledger run data/orders.csv data/payments.xlsx --out runs/week-01
```

欄名不同或活頁簿有多張工作表時，依 README 的 JSON 範例建立規則，再加入 `--rules rules.json`。每次使用新的輸出資料夾；程式不覆蓋舊報告，也不更動原始檔。

## 人工確認

展示中 `00047` 與 `0047` 的金額與幣別相同，但編號不同，程式不會猜測。按 **Pair records**，選 `orders:8` 與 `payments:7`，填入審核人及依據，按 **Add decision**，再按 **Export review** 下載 `review.json`。若瀏覽器阻擋下載，可複製頁面顯示的 **Review JSON**，另存 UTF-8 的 `review.json`。

把下載檔移到專案資料夾，再執行：

```sh
rowledger run runs/demo/inputs/orders.csv runs/demo/inputs/payments.csv \
  --review review.json --out runs/demo-reviewed
```

將得到 6 組匹配、14 筆待確認；原編號保留，人工匹配與自動匹配分開標示。金額不同、幣別不同、無效資料及已匹配資料不能被強制核准。輸入檔或規則改變時，舊審核檔會被拒絕。

網頁的新增決策只有匯出後才會保存；重新整理前務必匯出。審核人是填寫紀錄，不代表已驗證身分或數位簽章。

## 看懂輸出

- `report.html`：離線審核頁，可直接用瀏覽器開啟。
- `results.xlsx`：結果與兩份原始表，文字儲存，前導零不會消失，公式不會執行。
- `results.json`：完整結果、來源、規則與審核紀錄。
- `review-template.json`：綁定本次資料的審核範本。
- `manifest.json`：輸出檔案的 SHA-256 檢查碼。

CSV 的位置是「第幾筆資料」，不是文字檔行號，因為一筆 CSV 可以包含換行；Excel 則標工作表與實際列號。

## 使用範圍

適用單筆訂單對單筆收款。重複編號、部分付款、拆單、手續費、退款與外幣換算需要另訂規則，本版不自動猜測或合併。金額不四捨五入；預設 USD/EUR 為兩位小數、TWD/JPY 為零位，可依來源系統明訂。

每份輸入上限 10 MiB、25,000 筆、100 欄；CSV 使用逗號與 UTF-8。Excel 編號必須儲存為文字，已遺失的零不能靠工具推回。非法控制字元會整份拒絕，避免匯出時無聲改寫資料。

報告含原始資料，需像原始檔一樣保管。GitHub 範例全部為合成資料。
